HuleEdu public research code

This directory defines the generated curated research-code edition of HuleEdu. HuleEdu is the only authored source for this edition.

The initial slice is intentionally narrow. It publishes the prediction-mapping module and its focused tests, together with the files that define and validate the curated boundary. The generated edition contains exactly the locked inventory and is safe to inspect without access to HuleEdu's private systems.
